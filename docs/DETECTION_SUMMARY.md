# 입자 검출 성능 문제 진단 및 해결 방안

## 🔴 핵심 문제
**사용자 확인 사실: ROI 영역(250×250 픽셀)에 실제 입자는 1개만 존재**
- 육안 확인: 상단 가운데 주변보다 더 어두운 영역 1개
- 입자 크기: 약 1nm

## 📊 기존 검출 결과 분석

### 1. 기존 방법 (emd_analysis_Size_histogram_Pt.py)
- **검출 수**: 1,067개 (ROI 250×250에서 추정 약 100+개)
- **문제**: **심각한 과검출 (false positive)**
- **원인**:
  - 임계값이 너무 낮음 (Li: 0.44, Otsu: 0.50)
  - Watershed가 노이즈도 입자로 분리
  - 신뢰성 필터가 충분히 엄격하지 않음

### 2. LoG 기반 방법
- **검출 수**: 1,568개 (전체 이미지)
- **문제**: 대부분 1.5nm로 검출됨 (비현실적)
- **원인**: 검출 범위 설정 문제

### 3. 개선 시도 1 (improved)
- **검출 수**: 19개 (ROI)
- **문제**: 여전히 18개 과검출
- **원인**: 임계값이 여전히 낮음

### 4. 개선 시도 2 (final_fixed)
- **99 percentile**: 0개 검출 (너무 엄격)
- **98 percentile**: 0개 검출 (너무 엄격)
- **95 percentile**: 0개 검출 (너무 엄격)

### 5. 대화형 방법 (interactive)
- **임계값 0.5**: 전체 영역이 하나로 검출됨 (너무 낮음)
- **필요**: 0.7~0.8 사이의 적절한 임계값

## 🎯 문제의 핵심

### 1. 임계값 설정의 딜레마
```
너무 낮음 (0.4~0.5)  → 과검출 (100+개)
적절함 (0.7~0.8)     → 1개 검출 목표
너무 높음 (0.95+)    → 0개 검출
```

### 2. 데이터 특성
- 픽셀 크기: 0.0335 nm/pixel
- 1nm 입자 ≈ 30 픽셀 직경 (≈ 700 픽셀²)
- 실제 입자와 노이즈의 강도 차이가 미세함

### 3. 전처리 효과
- 백그라운드 제거: 효과적
- CLAHE: 대비는 향상되나 노이즈도 증폭
- 가우시안 블러: 너무 강하면 입자가 흐려짐

## ✅ 권장 해결 방안

### 방안 1: 대화형 도구 사용 (현재 구현됨)
**파일**: `interactive_detection.py`

**사용법**:
```bash
python interactive_detection.py
```

**절차**:
1. ROI 설정 (1024, 1024, 250)
2. 히스토그램 확인
3. 임계값 선택:
   - **Otsu (0.74) 또는 Li (0.70) 시도**
   - 수동: **0.7~0.8 범위** 권장
4. 검출된 각 영역을 육안으로 확인
5. 실제 입자만 선택

**장점**:
- 사용자가 각 후보를 직접 확인
- 과검출/오검출 수동 제거
- 가장 정확한 결과

### 방안 2: 기존 코드 수정

#### 수정 1: 임계값 범위 조정
```python
# 기존
threshold = filters.threshold_li(analysis_data)  # 0.44

# 개선
threshold_li = filters.threshold_li(analysis_data)
threshold_otsu = filters.threshold_otsu(analysis_data)
# 두 값 중 더 높은 값 + 10% 상향
threshold = max(threshold_li, threshold_otsu) * 1.1
```

#### 수정 2: 최소 크기 증가
```python
# 기존
min_particle_size = 10-50 픽셀²

# 개선 (1nm 입자 기준)
target_diameter = 1.0  # nm
target_area = np.pi * (target_diameter / 2) ** 2
min_particle_size = int(target_area / (pixel_size_x ** 2) * 0.5)  # 절반 허용
# 약 300 픽셀²
```

#### 수정 3: 강도 대비 필터 강화
```python
# 입자는 주변보다 최소 50% 어두워야 함
contrast_threshold = 1.5  # 기존: 1.3

# 입자 내부 강도가 전체 평균보다 낮아야 함
if mean_intensity > np.mean(analysis_data):
    continue  # 제외
```

## 🔍 검증 방법

### 검출이 정확한지 확인:
1. ✅ 검출 수가 1개
2. ✅ 위치가 "상단 가운데" (ROI 내 중상단)
3. ✅ 크기가 약 1nm
4. ✅ 주변보다 확실히 어두움
5. ✅ 원형에 가까움

## ⚠️ 주의사항

- **과검출이 훨씬 더 심각한 문제**: 19개 → 1개로 줄여야 함
- **임계값이 핵심**: 0.05 차이로도 결과가 크게 달라짐
- **시각적 확인 필수**: 자동화만으로는 불완전
- **각 이미지마다 최적값이 다를 수 있음**: 대화형 도구 권장
